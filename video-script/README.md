# Presentation and English-expression materials

Selected script drafts, the English expression bank, and the demo's end card are included as supporting materials. They preserve the development and recording process, rather than describing the latest software configuration.

In particular, older opening-script wording about everything running locally or a “training dataset” is superseded by the current README: the finished demo uses a remote DeepSeek conversation API and a researched persona prompt, without Charlie-specific LLM fine-tuning.

Private microphone recordings, phone-transfer inventories, raw transcripts, and review clips are not published. The completed videos are linked from the main README.
